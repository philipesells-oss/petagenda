## Descrição

Gerenciar templates de mensagens WhatsApp: listar globais + customizados, criar/editar/deletar templates personalizados, toggle ativo/inativo e preview ao vivo com variáveis interpoladas.

- [ ] Editor com campo de corpo e preview ao vivo com variáveis de exemplo
- [ ] Toggle ativo/inativo por template
- [ ] Chips das variáveis disponíveis clicáveis (inserem `{{var}}` no cursor)
- [ ] Link "Templates" na página `/whatsapp`

## Notas Técnicas

- `is_default = true` → template global (sem tenant_id) → READ ONLY na UI
- Preview: substituir `{{client_name}}` → "Maria", `{{pet_name}}` → "Rex", etc.
- Variáveis extraídas automaticamente do corpo via regex `\{\{(\w+)\}\}`
- Categoria disponíveis: reminder, confirmation, reactivation, post_service, promotion, custom
- Schema: `content` (não `body`) e `is_default` (não `is_global`)
