## Descrição

Enviar automaticamente mensagens de confirmação ao criar agendamentos e lembretes 24h/2h antes via cron jobs Vercel, respeitando opt-in do cliente e limites do plano.

---

## Acceptance Criteria

- [ ] Ao criar agendamento: server action dispara mensagem de confirmação (se opt-in ativo)
- [ ] API route `/api/cron/reminders` com proteção via CRON_SECRET
- [ ] Cron envia lembretes 24h e 2h antes do agendamento
- [ ] Log de mensagens em `message_logs` com status (pending → sent | failed)
- [ ] Webhook `/api/webhooks/zapi` recebe delivery status da Z-API e atualiza log
- [ ] Respeito ao opt-in (whatsapp_opt_ins) e limite de mensagens (messages_used vs messages_limit)
- [ ] Página `/whatsapp/logs` com histórico de mensagens enviadas
- [ ] `vercel.json` com cron configurado

## Notas Técnicas

- Cron endpoint chamado pelo Vercel a cada 30min: `0,30 * * * *`
- Header obrigatório: `Authorization: Bearer {CRON_SECRET}`
- Busca appointments onde `appointment_date = TODAY + 1 day` (24h) ou `date + time = NOW + 2h`
- Incrementa `tenants.messages_used` via RPC após envio bem-sucedido
- Webhook Z-API envia `{ messageId, status: "sent"|"delivered"|"read" }`
- Tabela de logs filtrada por tenant via RLS (service role para cron/webhooks)
