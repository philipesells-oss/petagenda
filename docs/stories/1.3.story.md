## Descrição

Implementar fluxo completo de autenticação (signup, login, forgot-password) com criação automática de tenant, e onboarding em 3 passos para novos pet shops.

## Dev Notes

- **Trigger-driven tenant creation:** `signUp` passes `{ full_name, shop_name, phone }` in `options.data`; the `handle_new_user()` DB trigger creates the tenant + user rows. No frontend insert needed.
- **Middleware already protects routes:** Story 1.1 middleware handles (a) unauth → `/login`, (b) auth on public → `/`, (c) canceled plan → `/settings/billing`. No duplicate logic added.
- **Onboarding completion detection:** inferred from presence of `business_hours` + `services` rows for the tenant. Dashboard banner reads this on every load (two `count: exact, head: true` queries — cheap).
- **Route group collision:** Next.js App Router merges `(auth)` and `(dashboard)` at `/`. The old `src/app/page.tsx` was deleted to avoid collision with `(dashboard)/page.tsx`.
- **Next.js 16 Suspense requirement:** `/login` reads `?next=` via `useSearchParams()` — must be wrapped in `<Suspense>` for static prerendering (build would fail otherwise).
- **Supabase types quirk:** With `PostgrestVersion: "12"` the `.insert()` overloads resolve the payload generic to `never`. Inserts are cast via `as never` while keeping a strongly-typed array variable upstream.
- **Open-redirect hardening:** `signIn` only honors `next` when it starts with `/` and not `//`.
- **Password reset anti-enumeration:** `resetPassword` always returns `ok: true`, regardless of whether the email exists.
