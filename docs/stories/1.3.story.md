# Story 1.3 — Autenticação e Onboarding

**Epic:** 1 — MVP Foundation
**Status:** Ready
**Agent:** @dev (Dex)
**Estimated:** 3-4h
**Depends on:** Story 1.1, Story 1.2

---

## Descrição

Implementar fluxo completo de autenticação (signup, login, forgot-password) com criação automática de tenant, e onboarding em 3 passos para novos pet shops.

---

## Acceptance Criteria

- [ ] Página `/signup` com campos: nome, email, senha, nome do pet shop, telefone
- [ ] Após signup: tenant criado + user associado como owner (via trigger DB)
- [ ] Redirect para `/onboarding` após signup
- [ ] Página `/login` com email/senha, link para forgot-password
- [ ] Página `/forgot-password` com envio de email de reset
- [ ] Layout `(auth)/layout.tsx` — sem sidebar, centrado, com logo
- [ ] `/onboarding` — stepper 3 passos:
  - Step 1: Horário de funcionamento (preenche business_hours)
  - Step 2: Serviços padrão (sugere Banho, Tosa, Banho+Tosa)
  - Step 3: WhatsApp (skip permitido)
- [ ] Redirect automático para `/` se já autenticado (nas páginas de auth)
- [ ] Proteção de rotas: usuário não autenticado → `/login`
- [ ] Plan canceled → redirect para `/settings/billing`
- [ ] Loading states em todos os forms

## Notas Técnicas

- Usar `@supabase/ssr` para autenticação server-side
- O trigger `handle_new_user()` no DB cria tenant + user automaticamente
- Metadata do signup: `{ full_name, shop_name, phone }` → passado para trigger
- Slug do tenant: gerado a partir do `shop_name` (minúsculas, apenas alfanumérico)
- Onboarding pode ser pulado, mas mostra banner até completar
