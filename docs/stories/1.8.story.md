## Descrição

Permitir que o pet shop configure horário de abertura/fechamento por dia da semana, com intervalo opcional (almoço). Base para validação de agendamentos.

---

## Acceptance Criteria

- [x] Página `/settings/hours` com 7 dias (domingo a sábado)
- [x] Toggle aberto/fechado por dia
- [x] Inputs de abertura, fechamento e intervalo (opcional) por dia
- [x] Botão "Copiar para todos os dias úteis" (seg-sex)
- [x] Submit salva via upsert em `business_hours` (UNIQUE tenant_id + day_of_week)
- [x] Feedback visual de sucesso (toast via sonner)
- [x] Validação: fechamento > abertura; break_end > break_start

## Notas Técnicas

- Schema: `business_hours(id, tenant_id, day_of_week, is_open, open_time, close_time, break_start, break_end)` com UNIQUE(tenant_id, day_of_week)
- Upsert via `.upsert(rows, { onConflict: 'tenant_id,day_of_week' })`
- day_of_week: 0=domingo … 6=sábado
- Server action valida via zod e executa dentro do tenant
