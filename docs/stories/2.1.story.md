## Descrição

Permitir ao admin do pet shop conectar seu número de WhatsApp ao sistema via Z-API, visualizar o status da conexão em tempo real, ver o contador de mensagens e desconectar/reconectar quando necessário.

- [ ] Contador de mensagens usadas vs limite do plano
- [ ] Botão Conectar / Desconectar / Reconectar
- [ ] Credenciais Z-API salvas na tabela `whatsapp_config`

## Notas Técnicas

- Z-API base URL: `https://api.z-api.io/instances/{instance}/token/{token}`
- QR Code endpoint: `GET /qr-code/image` → retorna `{ value: "base64..." }`
- Status endpoint: `GET /status` → retorna `{ connected: bool, phone: string }`
- Disconnect: `POST /disconnect`
- Credenciais ficam em `whatsapp_config` (server-side only, nunca no client)
- Polling de status: `setInterval` no client a cada 5s enquanto `connecting`
- Se não há `zapi_instance` configurado, mostrar formulário de setup
